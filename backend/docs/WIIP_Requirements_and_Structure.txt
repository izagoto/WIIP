====================================================================
WhatsApp Investigation Intelligence Platform (WIIP) 
====================================================================

RINGKASAN EKSEKUTIF
-----------------
Visi: Menjadi platform intelijen investigasi terkemuka di dunia yang mampu mengubah bukti digital menjadi wawasan investigasi yang dapat ditindaklanjuti.
Misi: Mengurangi waktu investigasi, mengeliminasi korelasi bukti manual, merekonstruksi sejarah komunikasi, mengungkap hubungan tersembunyi, mendeteksi perubahan perilaku, mendukung investigasi berbasis bukti, dan mempertahankan analisis yang dapat dipertanggungjawabkan (court-defensible).
Filosofi Produk: Menjawab "Bagaimana semua potongan bukti ini saling terhubung?" bukan sekadar "Bukti apa saja yang ada?".
Slogan: Lebih dari sekadar Forensik WhatsApp. Dibangun untuk Intelijen Investigasi.

FONDASI SISTEM (4 MESIN UTAMA)
----------------------------------
1. Mesin Korelasi (Correlation Engine)
   - Menghubungkan setiap artefak digital dari jumlah database WhatsApp yang tidak terbatas.
   - Objek: Orang, Nomor Telepon, Perangkat, Chat, Grup, Media, Voice Note, Panggilan, Lokasi, Dokumen, Hyperlink, Timestamp.
   - Kemampuan: Korelasi Multi-Database, Pencari Entitas Bersama (Kontak, Grup, Media, dll.), Deteksi Duplikat, Korelasi Timeline, Perbandingan Pesan, Deteksi Bukti/Pesan Hilang, Rantai Forward/Balasan/Kutipan (Forward/Reply/Quote Chains).

2. Mesin Perilaku (Behavior Engine)
   - Menganalisis perilaku komunikasi digital (memperlakukan perilaku itu sendiri sebagai bukti).
   - Analisis Pola Komunikasi: Pola Aktivitas (Harian/Mingguan/Bulanan), Jam Aktif, Jam Sibuk, Frekuensi, Waktu Respon, Durasi.
   - Deteksi Perubahan Perilaku: Deteksi Lonjakan (Burst), Periode Senyap, Kemunculan/Menghilangnya Kontak, Pergantian Kontak, Penurunan/Peningkatan Aktivitas Tiba-tiba, Keluar/Masuk Grup, Pola Penghapusan/Penerusan(Forward)/Lokasi.
   - Indikator: Skor Aktivitas, Stabilitas, Skor Interaksi, Konsistensi, Kekuatan Hubungan.

3. Mesin Timeline (Timeline Engine)
   - Mengubah bukti yang terisolasi menjadi satu timeline investigasi kronologis yang berkelanjutan.
   - Objek: Pesan, Panggilan, Gambar, Video, Voice Notes, Dokumen, Lokasi, Pesan Dihapus/Diteruskan, Balasan, Kutipan.
   - Kemampuan: Timeline Terpadu, Tangkapan Sejarah (Historical Snapshot), Putar Ulang (Replay) Timeline, Perbandingan, Korelasi Peristiwa, Rantai Cerita (Story Chain), Putar Ulang Investigasi.

4. Mesin Graf (Graph Engine)
   - Merepresentasikan setiap objek bukti sebagai graf investigasi yang saling terhubung.
   - Kemampuan: Graf Hubungan, Pemetaan Keluarga, Deteksi Komunitas/Lingkaran Tersembunyi (Hidden Circle), Irisan Kontak/Grup, Evolusi Hubungan, Deteksi Orang Penghubung (Bridge Person), Matriks Komunikasi.

MODUL PRODUK
---------------
1. Manajemen Kasus (Case Management): Dashboard, Manajer Bukti, Penugasan Investigator, Chain of Custody, Audit Trail, Verifikasi Hash, Tag, Bookmark.
2. Pemrosesan Bukti (Evidence Processing): Impor/validasi bukti (DB WA, DB Kontak, Media, Backup, Ekspor), Parsing, Ekstraksi Metadata, Indeksasi, Deteksi Duplikat.
3. Intelijen Orang (People Intelligence): Profil Kontak, Alias, Jumlah Komunikasi, Hari/Jam Aktif, Kontak/Grup Favorit, Bukti/Lokasi Bersama.
4. Intelijen Percakapan (Conversation Intelligence): Explorer Chat/Topik, Pencarian Kata Kunci, Statistik, Percakapan Terlama/Paling Aktif, Heatmap.
5. Intelijen Media (Media Intelligence): Browser Media, Deteksi Duplikat (Gambar/Video/Dokumen), Media Bersama, OCR, Metadata Viewer, Timeline Media.
6. Intelijen Lokasi (Location Intelligence): Tampilan Peta, Timeline Lokasi, Deteksi Titik Pertemuan, Analisis Lokasi Bersama/Umum, Riwayat Rute, Korelasi Geografis.
7. Ruang Kerja Investigasi (Investigation Workspace): Ruang kerja terpadu, Pin entitas (Kontak, Pesan, Media, Lokasi, Grup).
8. Pelaporan (Reporting): Menghasilkan PDF, HTML, Excel, JSON. Berisi Ringkasan Eksekutif, Timeline, Graf, Rangkuman, Hasil Korelasi, Chain of Custody.

FITUR ANDALAN (KILLER FEATURES)
---------------
- Live Correlation Board (Pembaruan otomatis pada timeline, graf, statistik, dll.)
- Behavior Intelligence (Identifikasi lonjakan, penurunan, dan perubahan ritme komunikasi)
- Story Chain (Menampilkan urutan komunikasi lengkap, bukan sekadar pesan terisolasi)
- Historical Snapshot & Case Replay (Melihat kondisi investigasi pada waktu tertentu dan memutar ulangnya)
- Relationship Evolution (Menganalisis hubungan Sebelum/Selama/Sesudah Insiden)
- Hidden Circle Detection & Common Evidence Finder (Deteksi grup/entitas tersembunyi dan pencari bukti serupa)
- Multi-Database Timeline & Investigation Gap Analyzer (Timeline gabungan dan deteksi celah bukti/pesan)
- Cross-Case Correlation (Mengkorelasikan entitas yang berulang antar kasus yang berbeda)
- Evidence Confidence Engine (Skor kepercayaan dan referensi bukti langsung)

====================================================================
USULAN STRUKTUR PROYEK BACKEND (CLEAN STRUCTURE)
====================================================================

Untuk mengimplementasikan sistem yang kompleks seperti WIIP, pendekatan arsitektur Modular Monolith sangat disarankan, dengan fokus eksklusif pada Backend untuk tahap awal ini. Berikut adalah struktur berbasis Python (FastAPI/Django) untuk Backend dan layanan pemrosesan (Worker).

WIIP-Project/
├── backend/                        # Sistem Backend utama
│   ├── app/                        # Source Code Aplikasi
│   │   ├── api/                    # Endpoint REST API / GraphQL
│   │   │   ├── v1/
│   │   │   │   ├── routes_case.py
│   │   │   │   ├── routes_evidence.py
│   │   │   │   └── routes_intelligence.py
│   │   ├── core/                   # Konfigurasi, Security, Database settings
│   │   ├── models/                 # Database Models (SQLAlchemy / Django ORM)
│   │   ├── schemas/                # Pydantic Schemas (Data Validation)
│   │   ├── services/               # Business Logic & CRUD Operations
│   │   ├── engines/                # 4 Core Intelligence Engines (Otak Sistem)
│   │   │   ├── correlation/        # Logika Graph & Hubungan Entitas
│   │   │   ├── behavior/           # Algoritma Scoring & Pattern Analysis
│   │   │   ├── timeline/           # Penyusunan Chronology & Story Chain
│   │   │   └── graph/              # Algoritma Node/Edge (NetworkX / Neo4j queries)
│   │   ├── modules/                # Fitur Moduler WIIP
│   │   │   ├── case_management/
│   │   │   ├── evidence_processing/# Ekstraksi SQLite, Parsing Crypt14/15
│   │   │   ├── people_intel/
│   │   │   ├── media_intel/        # Integrasi OCR, Hashing, Exif
│   │   │   └── reporting/          # Generator PDF, HTML, Excel
│   │   └── main.py                 # Entry point backend
│   ├── requirements.txt
│   └── Dockerfile
│
├── worker/                         # Background Task Processing (Celery)
│   ├── tasks/
│   │   ├── evidence_parser.py      # Task berat untuk memproses ratusan MB database WA
│   │   ├── media_processor.py      # OCR dan Hashing berjalan di background
│   │   └── correlation_runner.py   # Menghitung Behavior Score & Graph di background
│   └── celery_app.py
│
├── data/                           # Penyimpanan Data (Volume)
│   ├── raw_evidence/               # File database mentah & media yang diupload
│   ├── processed/                  # Hasil ekstraksi media / dokumen
│   └── exports/                    # Report hasil generasi
│
├── docker-compose.yml              # Orkestrasi Docker (Backend, Postgres, Neo4j, Redis/RabbitMQ)
├── README.md                       # Dokumentasi Instalasi
└── .gitignore                      # Ignore rule

Teknologi Rekomendasi:
- Backend: Python (FastAPI untuk performa tinggi, atau Django untuk integrasi admin & ORM yang matang)
- Graph Database: Neo4j (Sangat direkomendasikan untuk fitur Graph Engine dan Hidden Circle Detection)
- Relational Database: PostgreSQL (Untuk Case Management dan penyimpanan metadata relasional)
- Background Jobs: Celery + Redis / RabbitMQ (Wajib karena pemrosesan Evidence memakan waktu lama)
